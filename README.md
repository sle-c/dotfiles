# Dotfiles

Custom dotfiles based on Thoughtbot's dotfiles for VIM and Tmux

## Installation

Run the following command to install the dotfiles:

```bash
git clone https://github.com/username/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

## Usage

This will install the general setup for a development environment including:

- Vim configuration
- Tmux configuration
- Shell configuration
- Git configuration
- Other useful tools and configurations
